SECURITY & CONTROLS
Privacy first
This test interface performs OCR-text analysis locally and does not make AI network requests.
What this demo stores
  • Document title, manually confirmed fields, and pasted OCR text (in browser localStorage).
  • No scanned images or API keys.
  • Data can be cleared in one step.
This web prototype uses browser storage, not encrypted secure storage. Use invented sample documents, not sensitive real records.
